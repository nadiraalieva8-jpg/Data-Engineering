# Real-Time Data Streaming Engineering Pipeline

An end-to-end data platform built to automate data fetching loops from an external REST API, manage data ingestion queues, and route records to an enterprise database system.

## 🛠️ System Infrastructure Architecture
* **Orchestration & Workflow Scheduling:** Apache Airflow
* **Containerization & Deployment Strategy:** Docker & Docker Compose
* **Message Queue & Data Ingestion (Future State):** Apache Kafka & Zookeeper
* **Database Target Layer (Future State):** Apache Cassandra

## 🚀 Execution & Verification
The system successfully schedules and isolates micro-batch API ingestion processes.
